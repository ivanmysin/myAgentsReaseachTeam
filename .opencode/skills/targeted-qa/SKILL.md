# Purpose

Ответить на конкретный научный вопрос, используя Zotero-библиотеку. Найти релевантные источники, извлечь точный ответ с цитатами и оценить уровень доказательности. Подходит для фактических, концептуальных, методологических и сравнительных вопросов.

# When to use

Активируй этот навык когда:
- Пользователь задаёт конкретный вопрос: «правда ли, что...», «какой механизм...», «какие данные о...», «существует ли evidence for...»
- Нужен быстрый факт-чекинг с научным обоснованием
- Требуется оценить уровень доказательности утверждения
- Вопрос узкий и конкретный (не обзор!)

# Inputs needed

Перед началом определи (можно без уточнения у пользователя, если вопрос ясен):
- Тип вопроса: фактический / концептуальный / методологический / сравнительный
- Требуемая глубина ответа: краткий (1-2 абзаца + 3-5 ссылок) или развёрнутый (полстраницы + 5-15 ссылок)

# Procedure

**Шаг 1 — Классификация вопроса:**
1. Фактический: «Какая концентрация X используется для Y?» → точные данные
2. Концептуальный: «Почему Z важен для...?» → объяснение с evidence
3. Методологический: «Как правильно измерять W?» → методические рекомендации
4. Сравнительный: «Что лучше: A или B?» → comparative analysis

**Шаг 2 — Многоканальный поиск в Zotero:**
1. `zotero_search_library` (q=<запрос>) — для точных терминов в title/abstract
2. `zotero_search_fulltext` (q=<запрос>) — для терминологии из глубины статьи
3. `zotero_search_annotations` (q=<запрос>) — нет ли уже готовых выделений по теме
4. `zotero_get_collections` (recursive=true) + `zotero_get_collection_items` — навигация по тематическим коллекциям
5. Цель: найти 5-20 наиболее релевантных статей

**Шаг 3 — Извлечение ответа:**
1. Для топ-статей: `zotero_get_item_details` + `zotero_get_item_abstract` — быстрое знакомство
2. Для наиболее релевантных: @reader с фокусом на конкретный вопрос
3. Всегда загляни в `zotero_get_annotations` — пользователь мог уже оставлять выделения по этому вопросу
4. Извлекай ТОЛЬКО информацию, релевантную вопросу

**Шаг 4 — Формулировка ответа:**
1. Прямой ответ на вопрос (1-3 предложения)
2. Развёрнутое обоснование с цитатами
3. Оценка уверенности: high / moderate / low confidence
4. Противоречия (если есть)

# Output format

На языке пользователя (см. `user_profile.md`, по умолчанию — русский). Это прямой диалог с пользователем, в отличие от черновиков статей:

```markdown
## Ответ: [краткий прямой ответ]

### Обоснование
[Развёрнутое объяснение с цитатами]

### Ключевые источники
| # | Статья | Zotero itemKey | Релевантность | Ключевой finding |
|---|--------|----------------|---------------|------------------|
| 1 | (Author et al., Year) | ABCD1234 | Прямой ответ | ... |
| 2 | (Author et al., Year) | XYZ5678 | Подтверждение | ... |

### Уровень уверенности: [High / Moderate / Low]
- High: сходятся данные из 3+ независимых групп
- Moderate: данные из 1-2 групп, или есть нюансы
- Low: косвенные данные, противоречия

### Противоречия (если есть)
- (Author1 et al., Year, itemKey: ABCD1234) vs (Author2 et al., Year, itemKey: XYZ5678): ...
```

# Quality bar (self-check)

- [ ] Прямой ответ дан в первом же предложении
- [ ] Каждое утверждение имеет ссылку (Author et al., Year) и/или Zotero itemKey
- [ ] Указан уровень уверенности с обоснованием
- [ ] Отмечены противоречия между источниками (если есть)
- [ ] Ответ на языке пользователя, научный стиль, без воды
- [ ] Не выходит за рамки вопроса (не превращается в мини-обзор)
- [ ] Если данных недостаточно — честно сказано об этом
- [ ] Учтены пользовательские аннотации, если они есть по теме

# Anti-patterns

- ❌ Начинать с общих слов вместо прямого ответа
- ❌ Превращать ответ на вопрос в полноценный обзор литературы
- ❌ Заявлять high confidence при наличии противоречий
- ❌ Отвечать на основе 1 статьи, если есть другие
- ❌ Давать ответ «по памяти» без проверки в Zotero
- ❌ Игнорировать методологические различия между статьями
- ❌ Игнорировать пользовательские аннотации (если они есть по теме)

# Examples

**Output:** «Да, ремапируют. Классические эксперименты (Muller and Kubie, 1987, itemKey: ABCD1234) показали... Однако степень ремапирования зависит от... (Colgin et al., 2008, itemKey: XYZ5678). Различают rate remapping и global remapping (Leutgeb et al., 2005, itemKey: DEF9012)...» Уровень уверенности: High (подтверждено 10+ исследованиями). 8 источников.
