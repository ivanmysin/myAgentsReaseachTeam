# Purpose

Спланировать и выполнить многоканальный поиск статей в Zotero-библиотеке пользователя: по метаданным, по полным текстам, по тегам и коллекциям, по пользовательским аннотациям. Скомбинировать результаты в ранжированный список с обоснованием релевантности.

# When to use

Активируй этот навык когда:
- Нужно найти статьи по теме (любой агент, любая задача)
- Пользователь просит «найди статьи о...», «поищи литературу по...»
- Это начальный этап более крупного навыка (literature-review, paper-introduction, и т.д.)
- Нужно оценить объём доступной литературы по теме в Zotero

# Inputs needed

- Поисковый запрос / тема (на английском для статей в Zotero)
- Критерии отбора: временной диапазон, теги, коллекции, itemType
- Ожидаемое количество результатов

# Tools (Zotero MCP)

Все инструменты — MCP-функции Zotero. Префикс `zotero_`.

1. **zotero_search_library** — основной поиск по метаданным
   - `q` — общий запрос (поиск по title/abstract/...)
   - `title` — поиск только по заголовку (с оператором contains/exact/startsWith/regex)
   - `yearRange` — диапазон годов ("2020-2023")
   - `fulltext` — поиск по полным текстам (внутри PDF)
   - `tag` — фильтр по одному тегу
   - `itemType` — фильтр по типу ("journalArticle", "book", "attachment"...)
   - `sort` — сортировка ("relevance" | "date" | "title" | "year")
   - `limit`, `offset` — пагинация
   - `mode` — режим обработки (minimal/preview/standard/complete)
   - `relevanceScoring` — включить ранжирование

2. **zotero_search_fulltext** — поиск по полным текстам PDF, возвращает фрагменты с контекстом
   - `q` — запрос
   - `itemKeys` — ограничить набор articleKeys
   - `mode` — режим вывода
   - `contextLength` — длина контекста вокруг совпадения
   - `maxResults` — лимит

3. **zotero_fulltext_database** — низкоуровневый доступ к кэшу
   - actions: list / search / get / stats
   - полезно для проверки, какие PDF проиндексированы

4. **zotero_search_annotations** — поиск по пользовательским аннотациям
   - `q` — текст
   - `colors` — фильтр по цветам (yellow=question, red=important, ...)
   - `tags` — фильтр по тегам аннотаций
   - `itemKeys` — ограничить статьями

5. **zotero_get_collections** — структура коллекций
   - `recursive=true` — полное дерево

6. **zotero_search_collections** — поиск коллекций по имени

7. **zotero_get_item_details** — метаданные конкретной статьи (для обогащения результата)

8. **zotero_get_item_abstract** — только абстракт

# Procedure

**Шаг 1 — Анализ запроса:**
1. Выдели ключевые концепции (2-5)
2. Для каждой концепции — список синонимов и связанных терминов (на английском)
3. Определи, какие поисковые каналы наиболее релевантны:
   - **metadata search** — для точных терминов в title/abstract
   - **fulltext search** — для терминов, которые скорее всего есть только в теле статьи
   - **collections** — если пользователь уже структурировал библиотеку тематически
   - **annotations** — если пользователь ранее выделял материал по теме

**Шаг 2 — Поиск по метаданным:**
1. `zotero_search_library` с общим запросом `q=<основной запрос>` (`limit: 30`, `sort: relevance`)
2. Параллельно: `zotero_search_library` с `title=<основной запрос>` — для точных попаданий в заголовок
3. Если заданы теги в `user_profile.md` или пользователь упоминал тему — `zotero_search_library` с `tag=...`
4. При наличии временного диапазона — добавляй `yearRange`

**Шаг 3 — Полнотекстовый поиск:**
1. `zotero_search_fulltext` с тем же запросом (если есть кэшированные full-text). `maxResults: 30`.
2. Если запрос длинный — разбей на 1–2 короткие смысловые части и повтори.
3. Объедини результаты шагов 2 и 3, удали дубликаты по `itemKey`.

**Шаг 4 — Навигация по коллекциям (если применимо):**
1. `zotero_get_collections` (`recursive=true`) — посмотри тематические коллекции пользователя.
2. `zotero_search_collections` с тематическим ключевым словом.
3. Для релевантных коллекций: `zotero_get_collection_items` — добавь статьи в пул.
4. Это даёт «длинный хвост» статей, которые могли не попасть в keyword/fulltext поиск, но тематически подходят.

**Шаг 5 — Пользовательские аннотации:**
1. `zotero_search_annotations` с тематическим запросом.
2. Фильтр по цветам, если пользователь использует систему (например, `["yellow"]` для вопросов, `["red"]` для важного).
3. Из найденных аннотаций извлеки `itemKey` и проверь, что эти статьи в пуле. Если нет — добавь.
4. Аннотации — сильный сигнал: пользователь уже отметил эту тему как важную.

**Шаг 6 — Декомпозиция сложного запроса:**
1. Если запрос содержит несколько чётко различимых аспектов (например, «вещество X», «состояние Y», «популяция Z»), разбей его на атомарные концепции.
2. Для каждой концепции независимо выполни `zotero_search_library` (`limit: 50`).
3. Найди **пересечение** множеств `itemKey` — только статьи, в которых встречаются все аспекты.

**Шаг 7 — Расширение по ключевым авторам:**
1. Из текущего объединённого пула извлеки всех авторов.
2. Определи наиболее часто встречающихся (≥2 публикаций в пуле).
3. Для каждого выполни `zotero_search_library` с `q=<фамилия>` (фильтр по году, если нужен).
4. Добавь найденные работы в пул.

**Шаг 8 — Финальное объединение и ранжирование:**
1. Собери уникальные `itemKey` из всех источников, удали дубликаты.
2. Взвешенное ранжирование на основе:
   - количества каналов, через которые нашлась статья (больше = релевантнее)
   - позиции в каждом канале
   - наличия пользовательских аннотаций (большой вес)
   - recency (если уместно)
3. Обогати топ-N метаданными через `zotero_get_item_details` (если нужно для финального отчёта).

**Шаг 9 — Сохранение:**
1. Сохрани результаты в `output/logs/search_log_<task>.md`
2. Включи: запросы, количество результатов по каналам, финальный ranked list с itemKey

# Output format

```markdown
## Search Results: "[Query]"
**Date:** YYYY-MM-DD
**Channels used:** metadata, fulltext, collections, annotations
**Total found:** N | **Top shown:** M

### Search Summary
| Channel | Query | Results |
|---------|-------|---------|
| metadata (q) | "..." | N |
| metadata (title) | "..." | N |
| fulltext | "..." | N |
| collection "X" | — | N |
| annotations | "..." | N |

### Ranked Results
| # | itemKey | Authors | Year | Title | Journal | Channels | Relevance |
|---|---------|---------|------|-------|---------|----------|-----------|
| 1 | ABCD1234 | Smith et al. | 2023 | Title... | Nature | metadata+annotations | High: ... |

### Grouped by Subtopic (if applicable)
**Subtopic 1:** ...
- [ABCD1234] (Author et al., Year) — 1 sentence rationale
```

# Quality bar (self-check)

- [ ] Использовано минимум 2 поисковых канала (не только metadata)
- [ ] Поисковые запросы на АНГЛИЙСКОМ языке
- [ ] Вариации запроса покрывают синонимы
- [ ] Удалены дубликаты по itemKey
- [ ] Для каждой статьи — краткое обоснование релевантности
- [ ] Полный текст НЕ загружается (только метаданные, абстракты, фрагменты fulltext)
- [ ] Пользовательские аннотации учтены
- [ ] Результаты сохранены в файл
- [ ] При большом количестве — группировка по подтемам

# Anti-patterns

- ❌ Использовать только metadata-поиск без fulltext — упускаешь терминологию из глубины статьи
- ❌ Игнорировать пользовательские аннотации — это самый сильный сигнал
- ❌ Делать один запрос и останавливаться — всегда пробуй вариации и разные каналы
- ❌ Загружать `zotero_get_content` с `mode: "complete"` на этапе поиска (это задача @reader)
- ❌ Возвращать unsorted list без ранжирования и обоснования
- ❌ Формулировать поисковые запросы на русском (большинство статей в Zotero на английском)

# Examples

**Input:** «Найди статьи о взаимодействии тета-осцилляций и синаптической пластичности в гиппокампе»
**Output:** 4 канала поиска: (1) metadata `"theta oscillations synaptic plasticity hippocampus"`, (2) metadata (title) `"theta phase LTP"`, (3) fulltext `"theta phase precession LTP induction"`, (4) annotations `"theta plasticity"`. Объединено 70 результатов → 25 уникальных → топ-15 с обоснованием релевантности. Помечены 3 статьи, найденные и через metadata, и через annotations — высокая релевантность.
